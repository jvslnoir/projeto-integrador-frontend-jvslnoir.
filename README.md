# Modern Club

## Sobre o Projeto

**Modern Club** é um catálogo de moda de luxo desenvolvido como **Projeto Integrador** para a disciplina de **HTML/CSS** do curso de **Análise e Desenvolvimento de Sistemas**.

O projeto foi desenvolvido com o objetivo de aplicar, na prática, conceitos fundamentais de desenvolvimento web, criando uma experiência visual moderna e elegante para apresentação de produtos premium.

O catálogo apresenta produtos inspirados em marcas de luxo, como:

- Sundek
- Armani
- Hugo Boss

Cada produto possui informações como imagem, descrição e preço, proporcionando uma estrutura semelhante a um catálogo de moda online.

---

## Funcionalidades

- Catálogo de produtos premium
- Exibição de imagens dos produtos
- Descrições detalhadas
- Informações de preços
- Formulário para cadastro na lista de novidades
- Seleção de marca favorita
- Campo para informar frequência de compra
- Estrutura preparada para futuras melhorias de responsividade

---

## Formulário de Novidades

O projeto possui um formulário desenvolvido para coletar informações de usuários interessados em receber novidades da Modern Club.

Os campos incluem:

- Nome
- E-mail
- Telefone
- Marca favorita
- Frequência de compra

O formulário utiliza boas práticas de acessibilidade e validação utilizando recursos nativos do HTML5.
